# 자막 번역기

<img src="assets/icon.png" width="128" alt="자막 번역기 아이콘">

영상 음성을 인식하고 바로 한국어로 번역해 자막 파일을 만드는 Windows 무설치 앱입니다.

**[최신 버전 다운로드](https://github.com/reezex0-ux/subtitle-translator-releases/releases/latest)**

## 사용법

1. 릴리스의 `SubtitleTranslator-…-portable-x64.zip`을 받습니다.
2. ZIP 전체를 쓰기 가능한 폴더에 압축 해제합니다.
3. 맨 위의 **자막 번역기.exe**를 실행합니다.
4. 영상·폴더를 선택하거나 창에 끌어 놓고 **자막 만들기**를 누릅니다.

압축 해제한 폴더의 맨 위에는 실행 파일과 `app` 폴더가 있습니다. 둘을 함께 두세요. Python이나 화면 번역기를 따로 설치할 필요가 없습니다.

한국어 자막은 영상과 같은 폴더에 **영상이름.srt**로 저장합니다. 원문(`.source.srt`)·이중언어(`.bilingual.srt`)도 함께 생성합니다. 하위 폴더까지 순차 처리하며 기존 자막을 덮어쓰지 않습니다.

## 모델과 실행 환경

- Windows 10/11 x64용입니다.
- 첫 사용 때 선택한 음성 인식·번역 모델을 인터넷에서 내려받습니다. 이후에는 재사용합니다.
- 모델·캐시는 `app/data`에 보관합니다. 업데이트할 때 이 폴더를 보존하세요.
- 음성 인식은 사용 가능한 NVIDIA GPU에서 실행하며, 사용할 수 없으면 CPU로 자동 전환합니다.
- 설정에서 `base`, `small`, `medium`, `turbo`, `large-v3`를 선택할 수 있습니다. 큰 모델일수록 더 많은 메모리와 준비 시간이 필요합니다.
- 음성 인식 중에도 인식된 자막부터 번역합니다.
- GPU에서는 여러 구간을 함께 인식하는 빠른 모드가 기본입니다. 기존 방식과 문구·구간 분할이 달라질 수 있으며 설정에서 기존 순차 인식을 선택할 수 있습니다.
- GPU 메모리가 부족하면 첫 인식 전에 기존 GPU 방식으로 재시도하며, CPU는 순차 인식을 사용합니다.
- 오디오 읽기·모델 로딩·음성 분석·인식을 구분해 경과 시간과 진행 상황을 표시합니다.
- MP4/MOV의 트랙 간 반복 탐색을 줄이고 큰 단위로 읽어 느린 드라이브의 오디오 준비를 개선했습니다.
- 영상 음성과 번역은 로컬에서 처리합니다. 유료 API 키가 필요 없습니다.

## AI·자동화용 CLI

압축 해제한 폴더에서 실행합니다.

```powershell
.\app\subtitle-translator.exe transcribe "C:\videos" --json
.\app\subtitle-translator.exe transcribe --help
```

`--json`은 영상별 상태·자막 경로·오류·인식 및 번역 개수를 JSON 하나로 반환하고, 진행 로그는 stderr로 출력합니다. 파일·여러 파일·폴더를 입력할 수 있습니다. `--asr-mode standard`로 기존 순차 인식을 선택할 수 있습니다.

성공·기존 자막 건너뛰기는 종료 코드 0, 실행 실패는 1, 사용법·입력 오류는 2, 취소는 130입니다. 부분 자막은 오류나 취소 후에도 보존합니다.

이 저장소는 Windows 실행 파일과 릴리스를 배포합니다. 포함된 라이브러리·모델의 출처 및 라이선스는 패키지의 `app/THIRD_PARTY_NOTICES.txt`에서 확인할 수 있습니다.
